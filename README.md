## Описание
Изучены основы ASP.NET Core: создание Minimal API, маршрутизация, возврат JSON, middleware (логирование, защита ключом).

## Список маршрутов
| Маршрут | Описание |
| :--- | :--- |
| `/` | Приветствие + время |
| `/me` | Данные студента (визитка) |
| `/calc/{a}/{b}` | Калькулятор (+, -, *, /) |
| `*` (fallback) | 404 — маршрут не найден |

## Главные выводы
1. **Порядок middleware важен** — если `MapGet` выше `Use`, middleware не сработает.
2. **Minimal API** — быстро и просто для прототипов.
3. **JSON сериализуется автоматически** с конвертацией в `camelCase`.

## Вопросы 
1. **Minimal API vs MVC:** Minimal — без контроллеров, для микросервисов; MVC — структурно, для крупных приложений.
2. **MapGet до Use:** Middleware не выполнится для этого маршрута.
3. **PascalCase → camelCase:** Стандарт JavaScript (фронтенд).
4. **Коды HTTP:** 401 — не авторизован; 404 — не найдено; 200 — OK.
5. **dotnet run vs watch:** `run` — обычный запуск; `watch run` — авто перезапуск при изменениях.
